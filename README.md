# Telecom Customer Churn Analysis

# Name: YUMVAGUSENGA Ange
# Reg No: 224014529
## Overview
This project is part of Computing Intelligence Lab 1. It analyzes telecom customer churn using Python in a Kaggle Notebook.

## Dataset
Telco Customer Churn dataset containing 7,043 customer records and 21 attributes.

## Analysis
- Data preprocessing and cleaning
- Demographic analysis
- Phone service analysis
- Contract and payment analysis
- Data visualization and interpretation

## Tools Used
Python, Pandas, NumPy, Matplotlib, Seaborn, and Kaggle.

## Conclusion
Contract type and payment method show strong associations with customer churn, helping identify opportunities to improve customer retention.
